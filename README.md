# 同词相遇（互联网联机版）

## 本地运行

需要 Node.js 18 或更高版本，无需安装依赖。

```powershell
npm start
```

打开 `http://localhost:3000`。

## 部署

将整个 `tongci-online` 目录上传到支持长期运行 Node.js 服务的平台：

- 启动命令：`npm start`
- 运行端口：平台提供的 `PORT` 环境变量（程序已自动读取）
- Node.js 版本：18 或更高

部署完成后，用平台提供的 HTTPS 地址打开游戏。玩家一创建房间，将邀请链接发送给玩家二即可异地游玩。

## 游戏规则

- 每轮双方各自提交一个词，提交前互相不可见。
- 两个词不同时，结果会加入对局记录，随后自动开始下一轮。
- 两个词相同时，游戏立即结束，并保留全部回合的双方答案。

## 注意

- 房间数据保存在运行内存中，服务重启后会清空。
- 无操作房间会在 6 小时后自动删除。
- 若部署平台会自动休眠，首次打开可能需要等待服务唤醒。
